# The AI Baroque Music Detection Quiz
This quiz was conducted September 29 through October 12, 2026, using [Tally.so](https://tally.so/). The link was posted publicly to [X/Twitter](https://x.com/aug5thmusic/status/2105280051059298354) and [Substack](https://aug5th.substack.com/p/human-or-ai-a-baroque-music-quiz?r=2g7m94). The quiz received over 100 responses.

Most of the MIDIs came from [Mutopia](https://www.mutopiaproject.org/), where they were listed as Public Domain. The others I made myself.

You are free to use the data however you like.
