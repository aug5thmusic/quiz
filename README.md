# The AI Baroque Music Detection Quiz

**Original announcement: [Human or AI? A Baroque Music Quiz](https://aug5th.substack.com/p/human-or-ai-a-baroque-music-quiz)**

This quiz was conducted September 29 through October 12, 2026, using [Tally.so](https://tally.so/). The link was posted publicly to [X/Twitter](https://x.com/aug5thmusic/status/2105280051059298354), [Substack](https://aug5th.substack.com/p/human-or-ai-a-baroque-music-quiz), and [LessWrong](https://www.lesswrong.com/posts/re2eErZJiB8ErcR9k/human-or-ai-a-baroque-music-quiz). The quiz received 118 complete responses.

Several of the quiz's MIDIs came from [Mutopia](https://www.mutopiaproject.org/), where they were listed as Public Domain. The rest were made by me.

Anyone is free to use the quiz data however they like.
